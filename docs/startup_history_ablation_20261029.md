# 启动诊断记录器修复与固定 token 历史对照（2026-10-29）

本轮只编译、压力测试和离线 TensorRT 解码；未启动机器人、仿真运动、相机或夹爪服务。实机切换继续暂停。未修改控制历史构造、增益、超时或停止保护，也未增加过渡。

## 记录器

原 Writer 在任意互斥锁争用时 try_lock 失败即丢弃；该路径已改为每个生产线程独立的有界 SPSC 队列，后台轮询写盘。线程首次注册仍有短锁；字符串序列化仍在调用线程，不能据此宣称硬实时无阻塞。队列满仍明确计数丢失，不无限分配积压。

结束记录增加 accepted、written、write_errors。采集入口要求无丢失、无写错误，两个计数均等于实际数据行数，否则失败。跨线程日志物理行顺序不保证时间顺序，分析事件必须按 time 对齐；同一生产线程顺序保持。关闭前必须停止生产者。

229 本机 8 线程各 1000 条、994 维负载测试：8000 接收、8000 写入、0 丢失、0 写错误；逐线程序号无重复且有序。容量1的高速溢出测试：2982 接收/写入、5018 丢失，总计8000，无静默丢失。底层及独立 decoder 编译通过，6项 Python 回归测试通过，git diff --check 通过。

这是压力测试验证；尚未用修复版重新采集完整仿真启动轨迹，旧三轮的27/15/352条丢失不会被修复或改判通过。

## 对照方法与证据边界

数据：outputs/sim_startup_audit_20261029_manual；产物：outputs/history_ablation_20261029/comparison.json 及 sha256.json。每轮保持首个实际 decoder 周期的64维 token、当前帧状态及全部 last_action 不变，仅替换前9帧传感器历史。每轮6种输入：原始、重复当前状态（合成）、仅关节位置、仅角速度/关节速度、仅重力、全部传感器历史。全部经实际独立 TensorRT decoder 与部署映射解码。

三轮原始994维输入复算最大误差均为0（预设 rtol=1e-3、atol=1e-4）。最终脚本生成的输入与已执行二进制输入逐元素相同。

历史来自仿真实测记录，按20ms重采样，候选锚点、样本时间和年龄已保存。它不是原底层精确DDS采样历史，更不是实机状态复原；last_action仍保留启动时的零值，所以是受控输入消融，不是完整闭环历史重建。缺失/非有限输入或历史缺口大于10ms会失败。旧轨迹整体不完整，但本次使用的单条完整994维输入可以独立复算。

## 三轮结果

以下是首目标相对当前实际关节位置的最大绝对差，单位rad；不是实际运动轨迹或最大电机速度。

- 203518：原始0.502；仅位置0.578；仅速度0.502；仅重力3.293；全部历史2.845；重复当前2.844。
- 203841：原始0.586；仅位置0.663；仅速度0.586；仅重力2.892；全部历史2.437；重复当前2.437。
- 203831：原始0.671；仅位置0.669；仅速度0.671；仅重力2.928；全部历史2.289；重复当前2.288。

各关节实际位置、目标、差值、raw action、最大差值关节索引均保存在 comparison.json。

证实：三轮原始首输入前9帧重力均为[0,0,+1]，当前帧接近[0,0,-1]。StateLogger::makeZeroEntry_ 将缺失四元数设为[0,0,0,0]；GatherHisGravityDir 对其调用现有旋转函数，产生上述非物理重力历史。不能将零四元数描述为单位姿态。

证实：固定token和当前状态时，仅替换重力历史就显著改变首输出；实测状态历史与重复当前状态两种处理均未减小本组首目标最大偏差。仅速度历史改动影响较小。

排除（仅本组离线对照）：简单填充实测历史或复制当前状态即可消除首目标跳变。

证据不足：该重力历史是否是实机跳变根因、训练时是否使用相同启动填充、延迟/窗口中段启动贡献多大，以及后续闭环演化。不能依据本轮修改生产历史初始化并恢复实机。
